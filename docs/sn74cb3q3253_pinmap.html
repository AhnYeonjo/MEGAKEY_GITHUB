🎯 SN74CB3Q3253PW 상세 핀맵 및 연결도

📍 MUX #1 (CH1/CH2 제어) - 상세 핀맵

📍 MUX #2 (CH3/CH4 제어) - 상세 핀맵

📋 핀 기능 상세 설명

핀 번호 핀 이름 기능 연결 설명
1 S (SEL) 채널 선택 Arduino A7/A9 0=Y0/Z0 선택, 1=Y1/Z1 선택
2, 3 1Y0, 1Z0 채널 0 출력 PC1/PC3 D+/D- 차동 신호 (SEL=0일 때)
4, 5 2Y0, 2Z0 예비 NC 듀얼 채널 (미사용)
6, 7 2Z1, 2Y1 예비 NC 듀얼 채널 (미사용)
8 GND 그라운드 Arduino GND 공통 그라운드
9, 10 1Y1, 1Z1 채널 1 출력 PC2/PC4 D+/D- 차동 신호 (SEL=1일 때)
11, 12 2B, 2A 예비 입력 NC 듀얼 채널 (미사용)
13, 14 1A, 1B 공통 입력 USB Hub D+/D- 입력 신호
15 OE 출력 활성화 Arduino A6/A8 0=출력 활성, 1=Hi-Z (차단)
16 VDD 전원 3.3V 3.3V 전원 공급

🔌 MUX #1 연결

  • 제어: A7(SEL), A6(OE)
  • 입력: USB Hub D+/D- → Pin 13/14
  • 출력1: Pin 2/3 → PC1
  • 출력2: Pin 9/10 → PC2
  • 전원: 3.3V + 0.1µF 캐패시터

🔌 MUX #2 연결

  • 제어: A9(SEL), A8(OE)
  • 입력: USB Hub D+/D- → Pin 13/14
  • 출력1: Pin 2/3 → PC3
  • 출력2: Pin 9/10 → PC4
  • 전원: 3.3V + 0.1µF 캐패시터
💡 중요 참고사항:
  • 각 MUX 칩은 독립적으로 동작하며, 하나만 활성화됨
  • 캐패시터는 VDD 핀(16번)과 GND 핀(8번) 사이에 직접 연결
  • USB 신호선은 차동 페어로 배선 (D+/D- 길이 매칭)
  • 미사용 핀(2Y0, 2Z0, 2Y1, 2Z1)은 플로팅 상태로 둬도 무방
  • CH5 선택 시 두 칩 모두 OE=1로 설정하여 USB 완전 차단
