📋 Pin Function Description

Pin # Pin Name Function Connection Description
1 S (SEL) Channel select Arduino A7/A9 0=select Y0/Z0, 1=select Y1/Z1
2, 3 1Y0, 1Z0 Channel 0 output PC1/PC3 D+/D- differential signal (when SEL=0)
4, 5 2Y0, 2Z0 Spare NC Dual channel (unused)
6, 7 2Z1, 2Y1 Spare NC Dual channel (unused)
8 GND Ground Arduino GND Common ground
9, 10 1Y1, 1Z1 Channel 1 output PC2/PC4 D+/D- differential signal (when SEL=1)
11, 12 2B, 2A Spare input NC Dual channel (unused)
13, 14 1A, 1B Common input USB Hub D+/D- input signal
15 OE Output enable Arduino A6/A8 0=output active, 1=Hi-Z (blocked)
16 VDD Power 3.3V 3.3V power supply

🔌 MUX #1 Connection

  • Control: A7(SEL), A6(OE)
  • Input: USB hub D+/D- → pins 13/14
  • Output 1: pins 2/3 → PC1
  • Output 2: pins 9/10 → PC2
  • Power: 3.3V + 0.1µF capacitor

🔌 MUX #2 Connection

  • Control: A9(SEL), A8(OE)
  • Input: USB hub D+/D- → pins 13/14
  • Output 1: pins 2/3 → PC3
  • Output 2: pins 9/10 → PC4
  • Power: 3.3V + 0.1µF capacitor
💡 Key Notes:
  • Each MUX chip operates independently and only one is enabled at a time.
  • Connect the capacitor directly between the VDD pin (16) and the GND pin (8).
  • Route the USB signal lines as differential pairs (D+/D- length matching).
  • The unused pins (2Y0, 2Z0, 2Y1, 2Z1) may be left floating.
  • When CH5 is selected, set OE=1 on both chips to fully block USB.
