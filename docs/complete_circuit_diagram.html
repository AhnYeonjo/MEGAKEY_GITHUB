🔌 MegaKey IR LED & USB 멀티플렉서 완전 회로도

📡 IR LED 송신 회로
🔄 USB 멀티플렉서 회로 (SN74CB3Q3253PW)
📦 필요 부품 목록

IR LED 회로

  • IR LED (940nm) × 1
  • 2N2222 NPN 트랜지스터 × 1
  • 저항 1kΩ × 1
  • 저항 100Ω × 1

USB 멀티플렉서

  • SN74CB3Q3253PW × 2
  • 0.1µF 세라믹 캐패시터 × 2
  • USB Type-A 포트 × 5
  • USB Type-B 포트 × 1

선택 사항

  • TVS 다이오드 (ESD 보호)
  • 페라이트 비드 (노이즈 필터)
  • LED 표시등 (상태 표시)
🔗 핀 연결 요약
Arduino 핀 연결 대상 기능 비고
D46 IR LED (via 2N2222) HDMI 스위처 제어 NEC 프로토콜 38kHz
A7 (61) MUX1 SEL CH1/CH2 선택 0=CH1, 1=CH2
A6 (60) MUX1 OE 칩1 활성화 Active LOW
A9 (63) MUX2 SEL CH3/CH4 선택 0=CH3, 1=CH4
A8 (62) MUX2 OE 칩2 활성화 Active LOW
⚙️ 채널 선택 진리표
채널 MUX1_SEL (A7) MUX1_OE (A6) MUX2_SEL (A9) MUX2_OE (A8) 활성 경로
CH1 0 0 (ON) X 1 (OFF) MUX1 Y0 → PC1
CH2 1 0 (ON) X 1 (OFF) MUX1 Y1 → PC2
CH3 X 1 (OFF) 0 0 (ON) MUX2 Y0 → PC3
CH4 X 1 (OFF) 1 0 (ON) MUX2 Y1 → PC4
CH5 (JAMMA) X 1 (OFF) X 1 (OFF) USB 차단 (HDMI만)
⚠️ 중요 사항:
  • SN74CB3Q3253PW는 3.3V 전원 사용 (5V 허용 I/O)
  • USB 차동 임피던스 90Ω ±10% 유지 필수
  • D+/D- 트레이스 길이 차이 5mm 이내
  • 각 MUX 칩 근처에 0.1µF 디커플링 캐패시터 배치
  • IR LED는 수신기 방향으로 정확히 향하도록 설치
  • CH5 선택 시 모든 USB 연결 차단 (JAMMA는 HDMI만 사용)
🎯 PCB 레이아웃 권장사항
  • 레이어 구성: 최소 2층 (신호/GND), 권장 4층 (신호/GND/전원/신호)
  • 트레이스 폭: USB 데이터: 0.2mm, 전원: 0.5mm 이상
  • 비아: 고속 신호 경로에 최소화 (채널당 2개 이하)
  • 그라운드: 연속적인 그라운드 플레인 필수
  • 컴포넌트 배치: MUX 칩을 USB 커넥터 가까이 배치
  • ESD 보호: USB 포트마다 TVS 다이오드 추가 권장
