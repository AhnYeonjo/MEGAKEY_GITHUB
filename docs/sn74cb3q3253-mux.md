# SN74CB3Q3253PW — USB Multiplexer Control

Two SN74CB3Q3253PW devices (dual 2:1 FET mux, 16-lead TSSOP, 3.3 V supply,
5 V-tolerant I/O) implement the KVM USB channel select. This page documents the
**chip-level control semantics verified against the firmware**. Channel routing and
the full board wiring are in [`circuit-ir-usb-mux.md`](circuit-ir-usb-mux.md).

> **Provenance.** This replaces `sn74cb3q3253_pinmap.html`. That page's per-pin
> numbers (physical pin ↔ signal) could not be verified against the TI datasheet
> from this repo and are **deliberately omitted** — confirm them in TI document
> `SN74CB3Q3253` (SCES560) before wiring. The old page's *Arduino* pin map was also
> wrong (see `circuit-ir-usb-mux.md` §2).

## Control semantics (verified in firmware)

Each chip is driven by two signals — a select and an output enable:

| Signal | Behaviour |
|---|---|
| `MUXn_SEL` | 0 → Y0 path, 1 → Y1 path |
| `MUXn_OE`  | **active low**: 0 = chip enabled, 1 = all ports Hi-Z (device appears unplugged) |

Firmware evidence: `setKvmChannel()` in `firmware/MegaKey_IO/MegaKey_IO.ino`
(direct GPIO) and the `SR_BIT_MUX*` block in
`firmware/MegaKey_AVR128DB64/MegaKey_AVR128DB64.ino` (74HC595 bits).

| Channel | SEL1 | OE1 | SEL2 | OE2 | Meaning |
|---|---|---|---|---|---|
| CH1 | 0 | 0 | X | 1 | chip 1 only, Y0 → PC1 |
| CH2 | 1 | 0 | X | 1 | chip 1 only, Y1 → PC2 |
| CH3 | X | 1 | 0 | 0 | chip 2 only, Y0 → PC3 |
| CH4 | X | 1 | 1 | 0 | chip 2 only, Y1 → PC4 |
| CH5 (JAMMA) | X | 1 | X | 1 | both Hi-Z — USB fully disconnected |

## Control signal sources

| Signal | Mega 2560 (v3.4) | AVR128DB64 (v4.0) |
|---|---|---|
| MUX1_SEL | GPIO `A10` | 74HC595 bit 6 |
| MUX1_OE  | GPIO `A12` | 74HC595 bit 7 |
| MUX2_SEL | GPIO `A14` | 74HC595 bit 8 |
| MUX2_OE  | GPIO `A15` | 74HC595 bit 9 |

## Wiring notes

- USB D+/D- is a differential pair: a full pair must switch together, and each chip
  provides two mux halves for exactly this. Which chip half carries D+ vs D−, and
  which player pair feeds which chip's common port, must match the PCB netlist —
  verify against the board silkscreen/datasheet pin assignment when servicing.
- Decoupling: 0.1 µF ceramic directly between VDD and GND of each chip.
- Supply is 3.3 V; USB signal levels are within spec since the FET switches pass the
  line end-to-end (signal is generated by the 3.3 V RP2040 hosts/devices).
- Unused mux halves may float.
- OE=1 on both chips (CH5) intentionally makes every host see an unplug — JAMMA mode
  uses the JVS bus on the AVR instead of USB.
